## 1. Welcome

This repository is the single source of truth for the operation of the Belgravia residence. It has been designed to run the estate to a consistent, discreet and professional standard whether or not the Family is in residence.

The Family resides primarily overseas and occupies the residence for approximately **60 days per year**. The estate must nevertheless remain **fully operational, secure and presentation-ready year-round**. Every document in this system supports that single objective.

## 2. How this system is organised

The system is divided into thirteen numbered folders. Numbering is deliberate — it keeps the structure stable when it is later migrated to Microsoft 365 / SharePoint.

| Folder | Purpose | Confidentiality |
|---|---|---|
| 00 Estate Manager (Private) | Command documents — dashboard, document control, improvement register | Estate Manager Only |
| 01 Operations | Day-to-day running — logs, planners, task registers, SOPs, visitor & delivery records | Department Only |
| 02 Staff | Handbook, contact register, uniform register | Department Only |
| 03 Property | House manual, maintenance, inventories, housekeeping & laundry | Department Only |
| 04 Projects | Capital projects register and action logs | Estate Manager + Chief Butler |
| 05 Contractors | Contractor register, visit reports, approved suppliers | Department Only |
| 06 Vehicles | Vehicle register, maintenance logs, parking | Department Only |
| 07 Procurement | Procurement tracker, supplier database | Department Only |
| 08 Finance (Private) | Asset register, cost tracking | Estate Manager Only |
| 09 Family Information (Private) | Arrival/departure checklists, preferences | Estate Manager + Chief Butler |
| 10 Emergency Procedures | Emergency directory, incident reporting | Shared Read Only |
| 11 Templates | Blank master templates for reuse | Shared Read Only |
| 12 Archive | Superseded and historical records | Estate Manager Only |

## 3. First actions for a new user

1. Read this document in full.
2. Read the **Belgravia Estate Management System Index** for the complete document register.
3. Read the **Staff Handbook** (`02 Staff`).
4. Review the **Standard Operating Procedures Manual** (`01 Operations`).
5. Review the **Emergency Contact Directory** (`10 Emergency Procedures`).
6. Familiarise yourself with the **House Manual** (`03 Property`).

## 4. Daily rhythm at a glance

- **Every day** — complete the Daily Operations Log; walk the house; check security, plant and post.
- **Every week** — complete the Weekly Planner; review the Master Task Register; hold the operations meeting.
- **Every month** — review Preventative Maintenance Schedule, inventories and vehicle logs.
- **Before every Family stay** — execute the Family Arrival Checklist.
- **After every Family stay** — execute the Family Departure Checklist.

## 5. Document standards

Every document carries a control block: Document Number, Version, Author, Date Created, Last Updated, Next Review and Confidentiality Level. Do not delete this block. Changes are recorded in the **Document Control Register** (`00 Estate Manager`).

## 6. File formats

- **Documents** are written in Markdown (`.md`) and are formatted for direct conversion to Microsoft Word with no restructuring.
- **Data / spreadsheets** are provided as CSV (`.csv`) with explicit headers and example rows, for direct import into Microsoft Excel.

Both formats are deliberate: they are clean, human-readable and version-control friendly, and they migrate cleanly into Microsoft 365.

## 7. Confidentiality

This is a private household. Nothing in this system — and nothing observed in the course of duties — is to be discussed, photographed or shared outside the estate team. Folders marked *(Private)* are restricted as shown in the table above.
