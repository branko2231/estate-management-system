## File formats

- **Documents** — Markdown (`.md`), formatted for direct conversion to Microsoft Word.
- **Data / spreadsheets** — CSV (`.csv`), with explicit headers for direct import into Microsoft Excel or Microsoft Lists.

Both formats are deliberate: clean, human-readable, and designed to migrate into Microsoft 365 / SharePoint with no restructuring. See [Future Migration to Microsoft 365](Belgravia%20Estate%20Management/Future%20Migration%20to%20Microsoft%20365.md).

## Confidentiality

This is a private household. Folders marked *(Private)* are access-restricted. Nothing in this repository is to be shared outside the estate team.
